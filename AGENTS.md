# Project context for agents

LiU Tentor is a Swedish web app for finding and studying past exams from
Linköping University. It includes PDF exam/answer viewing, AI chat, quizzes,
course study material, and user accounts.

## Package manager and commands

- Use **pnpm** for all dependency management and project commands. Do not use
  Bun/bunx, npm/npx, or Yarn, even if they are installed on the machine.
- `package.json` declares the pnpm version in `packageManager`. Keep
  `pnpm-lock.yaml` as the only package-manager lockfile.
- Install dependencies: `pnpm install`.
- Add/remove dependencies: `pnpm add <package>`, `pnpm add -D <package>`,
  `pnpm remove <package>`.
- Run local tools with `pnpm exec <tool>`; use `pnpm dlx` for one-off tools.
- Development: `pnpm dev`. Keep port **5173** because the AI service allows that
  localhost origin. Reuse an existing dev server when available.
- Build and typecheck: `pnpm build` (`tsc -b` followed by Vite).
- Lint: `pnpm lint` (Oxlint).
- Format: `pnpm format`; check formatting: `pnpm format:check` (Prettier).
  For a small change, format only the touched files with `pnpm exec prettier`.
- Preview the production build: `pnpm preview`.
- There is currently no test script. Choose checks appropriate to the change;
  do not assume a test runner is configured.

## Architecture

- **Frontend:** React 19, TypeScript, Vite, and ES modules. `src/main.tsx`
  initializes auth, font settings, input modality, analytics, and providers.
- **Routing:** TanStack Router with file-based routes in `src/routes/`.
  `src/router.tsx` configures the router and query-client context.
  `src/routeTree.gen.ts` is generated by the router plugin; do not edit it by hand.
- **Server data:** TanStack Query. Query definitions and hooks live in
  `src/queries/`; API clients and domain helpers live in `src/lib/`.
- **Client state:** Zustand stores in `src/stores/`. Read stores through selectors.
  Some stores persist preferences/data in browser storage.
- **Components:** Feature components live in `src/components/<feature>/`.
  `src/components/ui/` contains shadcn/ui primitives built on Radix;
  `src/components/shared/` contains shared app compositions.
- **Styling:** Tailwind CSS v4 through the Vite plugin. `src/index.css` defines
  theme/color tokens and base styles; `src/styles/app.css` contains font setup
  and additional app styles. Features also have local CSS where needed.
  Use existing tokens and the `cn` helper in `src/lib/utils.ts`.
- **Imports/types/hooks:** `@/` resolves to `src/`. Shared domain types live in
  `src/types/`; reusable hooks live in `src/hooks/`.
- **PDFs:** EmbedPDF and its plugins render and manage exam documents.
- **Chat content:** Markdown-it, DOMPurify, KaTeX/texmath, and Shiki handle
  Markdown, sanitization, math, and syntax highlighting.
- **Other UI tools:** Lucide icons, Framer Motion, Recharts, and Sonner.

## Services and hosting

- Supabase provides authentication and user data (`src/lib/supabase.ts`).
- Exam/course data comes from the external Go API through `/api/go`
  (`src/lib/api.ts`). Vite proxies this in development; Netlify rewrites it
  in production.
- AI chat uses a separate service configured by `VITE_AI_API_URL`
  (`src/lib/chat-api.ts`) and streams responses using server-sent events.
- Netlify hosts the built `dist/` directory. `netlify/functions/` contains upload,
  feedback, sitemap, and revalidation handlers; `netlify/edge-functions/seo.ts`
  handles initial-response SEO metadata.
- `pnpm dev` serves upload/feedback functions through `netlify-functions-dev.ts`;
  a separate Netlify CLI is not required for these endpoints.
- See `.env.example` and `README.md` for environment setup. Keep private values
  out of source code and documentation.

## Typography

- **Google Sans Flex** is the default font for interface and chat text, with an
  optional **System** setting and a separate custom font for the **LiU Tentor logo**.
  Respect the selected setting; do not assume a system-font fallback is intended.
- Font selection is persisted in `src/stores/settings.ts` and applied by
  `src/lib/font-settings.ts` through `data-ui-font` on the root element.
  `--ui-font` controls interface text; `--chat-font` follows it.
- Google Sans Flex remains an available setting and is currently the default
  for a fresh settings store. An existing saved System selection overrides it.
  Do not confuse the fresh-store default with the user's saved preference.
- The logo uses `font-logo` and the local `gt-super-text-bold.woff2` asset.
  Code/monospace text currently uses Google Sans Code; rendered math and PDFs
  have their own typography.

## Working conventions

- Follow the existing feature structure and reuse shared components.
- Keep user-facing text Swedish unless the surrounding feature uses another language.
- Preserve unrelated local changes and avoid editing generated/build output.
- Keep this file updated when architecture, tooling, or project conventions change.
